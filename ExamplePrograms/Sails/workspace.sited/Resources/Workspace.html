Quick Reference

Basic expressions:
3 + 4 - arithmetic
'Hello' , ' World' - string concatenation
[1, 2, 3] collect * 2 - collections
x := 42. x * 2 - local variables

Keyboard shortcut: Cmd+Enter (or Ctrl+Enter) to evaluate
Print It: Select an expression, then evaluate — result is inserted after the selection
